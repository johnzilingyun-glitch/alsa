7.1 简化凯利公式计算

f* = (b × p - q) / b

其中：
b = 赔率 = 牛市上行 / 熊市下行
  = (28.50 - 16.00) / (16.00 - 10.00)
  = 12.50 / 6.00
  = 2.083

p = 胜率 = 牛市概率 = 20%
q = 败率 = 1 - p = 80%

f* = (2.083 × 0.20 - 0.80) / 2.083
   = (0.4167 - 0.80) / 2.083
   = -0.3833 / 2.083
   = -0.184

7.2 凯利结果解读

  • 原始凯利 f* = -18.4% → 负值意味着不应下注
  • 若以入场价$16.00重新计算：b = (28.50-16)/(16-10) = 12.50/6 = 2.083 → 不变。胜率仍为20%。f*仍为负。
