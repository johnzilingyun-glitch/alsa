# 静谧阿尔法研究员 (Serenity Alpha Analyst)

## 定位

核心原则：将推动市场的新闻和可观察需求变化，转化为具有可投资性的阿尔法假设，寻找财报弹性极高的小市值公司。

> 不要只问新闻本身是否宏大，而要问：一个已可观察的需求变化，是否足以重写一家小市值公司的财务报表？

**核心工作流**：新闻 → 已发生的需求变化 → 收入/利润传导链条 → 小盘股业绩弹性 → 验证路径

---

## 核心规则

| 规则 | 内容 |
|------|------|
| 区分谈资与真实需求 | 识别事件是叙事还是实际需求拐点 |
| 现象翻译为财务指标 | 映射到利润表/资产负债表项目 |
| 寻找小盘/纯粹/被误判标的 | 优先"卖铲人"而非巨头 |
| 测试市场误分类 | 市场当前认知 vs 真实身份 |
| 构建验证链条 | 可观察节点（营收指引、订单、ASP） |
| 基于证据定仓位 | 条件式指导（观察/试错/加仓/放弃） |

**核心判断标准**：α弹性 = 增量需求对营收的边际贡献 / 当前市值

---

## 分析方法论

### Step 1: 需求真伪鉴别

| 等级 | 定义 | 证据标准 | 操作指引 |
|------|------|---------|---------|
| L1 已兑现 | 需求体现在财报/订单/排产 | 季报、订单公告、渠道调研 | 可考虑建仓 |
| L2 可观察 | 需求拐点可通过高频数据验证 | 价格指数上涨、开工率提升 | 小仓试错 |
| L3 仅叙事 | 仅有政策/新闻/概念 | 一级市场或政策文件 | 仅观察 |

### Step 2: 财务传导映射

```
因为 [X 发生]
→ 对 [Y 产品/服务] 需求 [增加/持续]
→ 通过 [收入项Z] 传导到 [目标公司群]
→ [N公司] 值得关注因为：
   • 市值仅 [X亿]
   • 该业务占营收 [Z%]
   • 增量需求 [A亿] / 当前营收 [B亿] = 弹性 [C%]
```

### Step 3: 小盘筛选标准

优选条件（满足3项以上）：

| 条件 | 阈值 |
|------|------|
| 市值 | < 200亿（A股）或 < 50亿港元 |
| 业务纯度 | > 50%（受益业务占营收比） |
| α弹性 | > 20%（增量需求/当前营收） |
| 机构关注度低 | 近3月研报 ≤ 3篇，北向/南向 < 5% |
| 非ST/非亏损 | 最近一期扣非净利润为正 |
| 供应链卡位 | 瓶颈环节或独占性位置 |

### Step 4: 市场误分类检验

| 维度 | 市场当前认知 | 需求持续后的真实身份 |
|------|------------|-------------------|
| 行业归属 | ? | ? |
| 估值锚 | PE/PB [?]x | 应按 [?] 重估 |
| 投资者类型 | 散户/游资为主 | 潜在机构化标的 |

### Step 5: 验证与证伪

设定可观察的验证/证伪节点及时间窗口。
